## Convenciones

- **OBLIGATORIO:** control que debe existir si se configura el supuesto jurídico señalado.
- **CONDICIONAL:** depende del material, rol, actividad, contrato, situación tributaria o alcance real de RexFy.
- **RECOMENDADO:** reduce riesgo o mejora evidencia, aunque la auditoría no identifica una obligación universal.
- **PENDIENTE:** falta información verificable o concepto especializado; bloquea cualquier conclusión definitiva.

Las versiones, aprobaciones y aceptaciones futuras deberán conservar fecha, responsable, texto exacto, usuario, empresa, contexto transaccional y evidencia técnica de integridad.
